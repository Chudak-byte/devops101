## 2. Порядок команд для запуску та управління

Перед виконанням команд переконуйтеся, що ви перебуваєте в директорії з відповідним `Vagrantfile`.

### Запуск та зупинка
* `vagrant up` — створити та запустити віртуальні машини.
* `vagrant halt` — вимкнути віртуальні машини.
* `vagrant destroy -f` — повністю видалити віртуальні машини та їхні диски.
* `vagrant status` — перевірити поточний стан машин.
